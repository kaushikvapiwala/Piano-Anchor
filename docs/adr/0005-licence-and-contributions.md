# 0005. Apache-2.0 licence, DCO sign-off, squash merges

- Status: accepted
- Date: 2026-11-10

## Context
The project welcomes contributors (including AI-assisted ones) and must stay clean-room and permissive.

## Decision
Apache-2.0. Contributions certified with the Developer Certificate of Origin (`git commit -s`), checked in
CI. Conventional Commit PR titles; one feature per PR; squash-merge only; `main` changes only through PRs.
No GPL code and nothing copied from vendor or commercial apps.

## Consequences
Low friction for contributors (no CLA). Relicensing later would need contributor consent.
