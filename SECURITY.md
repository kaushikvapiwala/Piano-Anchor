# Security policy

Please report vulnerabilities **privately** through GitHub:
[Report a vulnerability](https://github.com/kaushikvapiwala/Piano-Anchor/security/advisories/new).
Do not open a public issue for security problems.

Piano Anchor keeps all learner data on the device. Sensitive areas include Bluetooth/USB MIDI handling,
data import/export, optional cloud sync, and the in-app update check. Only the latest release is supported.
